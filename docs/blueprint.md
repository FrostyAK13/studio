# **App Name**: DerivInsight Pro

## Core Features:

- Real-time Data Stream: Securely connect to the Deriv API using an APP ID to fetch and display real-time synthetic indices data, ensuring up-to-the-minute analysis.
- Interactive Charting: Visualize synthetic market price movements with interactive and customizable charts, including candlestick and line graphs, to aid in digit analysis.
- Basic Technical Indicators: Apply fundamental technical analysis indicators (e.g., Moving Averages, RSI, Bollinger Bands) directly to the real-time and historical charts.
- Digit Pattern Assistant: An AI-powered tool that analyzes real-time last digit ticks of synthetic indices, identifying recurring patterns and anomalies to provide potential insights.
- Historical Data Viewer: Access and review past synthetic market data across various timeframes to validate strategies and understand long-term trends.
- Customizable Watchlist: Allow users to create and manage a personalized watchlist of their most-followed synthetic indices for quick access and monitoring.

## Style Guidelines:

- Primary color: A vibrant, clear blue (#4D92EA), chosen to evoke a sense of trust, technology, and analytical clarity. This color will be used for interactive elements and key highlights.
- Background color: A very dark, almost black, with subtle blue undertones (#14171A). This dark scheme provides high contrast for data visualizations and reduces eye strain during prolonged analysis sessions, maintaining focus on the analytical content.
- Accent color: A bright aquamarine/mint green (#4DEAEA), providing a cool, analogous contrast to the primary blue. This color signifies insights and growth, used for alerts or important data points.
- Headline and body font: 'Inter', a modern sans-serif chosen for its objective, neutral, and highly legible appearance, which is ideal for data-intensive financial analysis tools.
- Use clean, geometric, and minimalist icons to complement the analytical and technological theme, ensuring clarity and unobtrusiveness within data-rich interfaces.
- Employ a modular, dashboard-like layout with clearly defined panels for data streams, charts, and analysis tools, optimized for readability and efficient data consumption on various screen sizes.
- Incorporate subtle and smooth transitions for data updates, chart manipulations (zooming, panning), and panel expansions, enhancing the user experience without being distracting.
